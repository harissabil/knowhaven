Di menu Integrasi (Integrations):
- Slack: klik Hubungkan Slack untuk memasang Havi di workspace. Havi bergabung otomatis ke channel publik; untuk channel private, undang @havi di channel itu. Pesan masuk secara real-time. Channel baru tersembunyi sampai dipetakan di Container & Izin.
- Jira dan Confluence: isi URL situs Atlassian, email, dan API token (buat di id.atlassian.com, Security, API tokens), lalu Tes & simpan. Token disimpan terenkripsi. Perubahan ditarik otomatis sekitar setiap 2 menit; klik Sinkronkan sekarang untuk menarik segera.
- Confluence juga bisa mengirim perubahan halaman seketika lewat Confluence Automation yang dipasang dari kartu Confluence.
